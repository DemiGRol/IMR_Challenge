# sync-documentation

1. Inspeccioná diff, contratos, requisitos y decisiones.
2. Identificá fuentes afectadas usando docs/diagrams/README.md.
3. Actualizá solo documentos pertinentes: USM, historias, contratos, estados, DER, arquitectura, DFD, pruebas.
4. Revisá consistencia de IDs, fuentes, versión y etiquetas propuesto/as-built. No inventes almacenamiento ni estados.
5. Actualizá contexto y backlog, registrá limitaciones y verificá links y sintaxis.
