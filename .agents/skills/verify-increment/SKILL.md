# verify-increment

1. Relacioná cambio con REQ/US y criterio.
2. Inspeccioná diff y determiná pruebas pertinentes.
3. Ejecutá comandos reales autorizados; distinguí fixtures/mocks de integración real.
4. Revisá XML/DI/semántica, importación, edición, UX, errores y seguridad según alcance.
5. Pedí revisión independiente si riesgo lo justifica; no permitas edición por revisor.
6. Registrá resultados, pendientes, documentos afectados y estado; no cierres requisitos sin evidencia.
