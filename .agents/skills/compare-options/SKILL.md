# compare-options

1. Definí problema, alcance, restricciones, criterio de éxito.
2. Mapeá categorías y opciones viables; incluí el enfoque simple y no incorporar componente si aplica.
3. Verificá fuentes, versiones, licencias, coste, integración y evidencia.
4. Compará beneficios, riesgos, plazo, mantenimiento, reversibilidad y aprendizaje. Proponé spike si faltan datos.
5. Presentá recomendación y condiciones que la cambiarían; esperá aprobación.
6. Registrá ADR aprobado usando docs/architecture/decisions/ADR-template.md; actualizá contexto y backlog. No escribas código en modo decisión.
