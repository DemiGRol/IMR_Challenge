# Inventario de modelos
| Modelo | Propósito | Fuente editable | Estado | Disparador de actualización |
|---|---|---|---|---|
| DFD-0 | Límite, entidades externas, flujos | Por decidir | pendiente | Cambios de alcance/actor/flujo |
| Arquitectura | Componentes y conexiones | Por decidir | pendiente | Cambio de diseño/ADR |
| Secuencia | Flujo generación/edición | Por decidir | pendiente | Cambio de contrato/interacción |
| Estados | Ciclo relevante de generación/editor | Por decidir | pendiente | Cambio de estados/transiciones |
| DER | Entidades y cardinalidad si aplica | Por decidir | pendiente de aplicabilidad | Cambio de dominio/esquema |

Cada modelo indica propósito, notación, alcance, propuesto/as-built, fecha o commit de referencia. Conservar fuente editable; no confundir DFD con secuencia ni BPMN. Si no hay persistencia, documentar esquema de datos/artefacto y no fabricar tablas.
